# 简行. JIANXING
简行：上传一次简历，自动填写每一份求职申请。

## 使用教程
# 一、插件安装
1. 首先将插件压缩包下载到本地，可以使用git 或者直接手动下载release并解压，记着解压文件的路径。

2. 插件可以在Edge或者谷歌浏览器中安装，这里以谷歌浏览器为例子，Edge也是同样的安装方式。
  
3. 首先在谷歌浏览器点击插件图标，然后进入插件设置，如下图所示：<p align="center"><img src="https://github.com/user-attachments/assets/47df09ac-d9a2-4263-af70-4b54ba8195d4"  width="300"></p>

5. 然后打开谷歌浏览器的开发者模式，加载未打包的程序，如下图所示：<p align="center"><img  src="https://github.com/user-attachments/assets/47e89802-f6e7-4ac2-91c1-99c5a12c791a" /></p>

6. 选择刚才解压的压缩包，这样就安装好了插件，安装完成如下图所示：<p align="center"><img  src="https://github.com/user-attachments/assets/f563c32a-f395-48ac-b2a9-90776e4f46f4" width="600" /></p>

7. 这是打开一个求职网站，选中简填即可打开填写界面，也可以按固定按钮将其固定到标题栏。：<p align="center"><img src="https://github.com/user-attachments/assets/965e3d10-5999-4abc-88e1-5ab524e2f498" width="300" /></p>


# 二、插件配置
由于本插件是借助ai来匹配关键字符，因此需要进行一些相关的配置
1. 首先点击插件图标，打开如下图左侧所示界面，这时打开管理面板，可以得到右图所示界面。在右图的基础信息里面可以进行信息新建以及重名名等操作，最后填写完基本信息即可。：<p align="center"><img width="2498" height="1285" alt="image" src="https://github.com/user-attachments/assets/20f580de-3fbd-496d-bff7-0f3bb99163db" /></p>

2. 添加AI 配置，打开下图左图所示的AI配置，到达下图右图，然后填写API请求地址、API Key、以及插件请求模型（如果暂时没有合适的 API Key，也可以了解 [Nemu API](https://nemu.mikushop.party/)，API获取教程可参考( https://blog.mikushop.party/archives/OpenAI-Api )中1.1的前五个步骤。**这是第三方服务，并非使用本插件的唯一选择；具体价格和活动请以其网站实际显示为准。**配置完成后，打开招聘表单即可尝试辅助填写。**提交前请自行核对姓名、联系方式、教育经历等信息。插件不会替你保证填写结果准确。**
最后，祝大家都能找到满意的工作！<p align="center"><img width="2787" height="1127" alt="image" src="https://github.com/user-attachments/assets/f6aeb94f-5e96-446c-b0bf-46643064c058" /></p>
