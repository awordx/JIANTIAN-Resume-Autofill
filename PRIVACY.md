# Public-source privacy policy

This repository contains source code and synthetic test fixtures only. It must not contain real resumes, application exports, browser profiles, credentials, API keys, identity numbers, contact details, or other personal data.

Before every public push, run the repository's privacy scan and review all newly added files. Do not commit files ignored by `.gitignore`; in particular, do not add imported resumes, exported profile backups, browser storage, `.env` files, private keys, or logs.
